A one-star review written by a house cat about its human, entered in make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
